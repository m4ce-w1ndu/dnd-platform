TAVOLO VIRTUALE · piattaforma per giocare a D&D (mappe, pedine, nebbia, dadi, schede)
==================================================================================

INDIRIZZI
  https://dnd.immovilli.trade           (pubblico, via Cloudflare)
  https://dnd.home.immovilli.trade      (rete di casa, tramite Caddy)
  http://192.168.0.2:8095               (diretto, rete di casa)

COME SI GIOCA (ciclo di una serata)
  1. All'avvio il tavolo è CHIUSO: entra solo l'amministratore (utente «admin»).
  2. L'admin sceglie l'avventura e APRE il tavolo → sala d'attesa.
  3. I giocatori entrano (con Discord/Google/GitHub o come ospiti, se ammessi) e scelgono il personaggio.
  4. Il Master preme «▶ Inizia la partita»: tutti vedono la mappa. ⏸ rimanda in sala d'attesa.
  5. A fine serata: 👑 Master → «🔒 Chiudi il tavolo». La partita resta salvata.

IMPOSTAZIONI (scheda ⚙️, solo admin) — niente file d'ambiente da toccare
  - nome utente e password dell'admin (servono la password attuale per cambiarle)
  - accesso con Discord / Google / GitHub: incolla Client ID e Secret; la pagina mostra
    la Redirect URI esatta da registrare sul sito del provider
  - ospiti ammessi sì/no, password del tavolo facoltativa
  - utenti: abilita chi può fare il Master (o l'admin), elimina utenti
  - dati: partite salvate (scarica / azzera) e backup del database

DATI
  Tutto è in un solo database SQLite: /var/lib/tavolo-virtuale/dati/tavolo.db
  (partite, utenti, account, impostazioni). Backup: ⚙️ → Dati → «Scarica backup».
  Le avventure sono cartelle in /var/lib/tavolo-virtuale/avventure (formato: FORMATO_AVVENTURE.md).

AGGIUNGERE UN'AVVENTURA
  dal browser:   👑 Master → 📚 Avventure → scegli il .zip → Carica
  da terminale:  python3 strumenti/crea_pacchetto.py ../La_Tana_di_Vermiglia --pubblica
  solo le mappe: copia immagine + .json in /var/lib/tavolo-virtuale/avventure/<id>/mappe/

AGGIORNARE IL PROGRAMMA DEL SERVER
    ./deploy/aggiorna.sh        (i browser aperti si ricaricano da soli con la nuova versione)

COMANDI SUL SERVER (ssh immauri@192.168.0.2)
    systemctl status tavolo.service
    journalctl -u tavolo.service -f
  Quadlet:  /etc/containers/systemd/tavolo-virtuale/{tavolo.build,tavolo.container}

PROVARLO SUL PROPRIO PC
    python3 server.py        → http://localhost:8000  (la password admin iniziale è stampata a video)
